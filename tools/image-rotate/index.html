사진이 옆으로 누워 보이는 이유

휴대폰은 사진을 찍을 때 픽셀을 항상 같은 방향으로 저장하고, '이 사진은 90도 돌려서 보여 줘'라는 회전 정보를 따로 붙여요. 휴대폰 갤러리는 이 정보를 읽어서 바로 세워 보여 주지만, 일부 게시판이나 오래된 프로그램은 회전 정보를 무시해서 사진이 옆으로 누워 보여요. 이 도구로 한 번 돌려서 저장하면 픽셀 자체가 바로 선 상태로 저장되기 때문에 어디에 올려도 같은 방향으로 보여요.

기울어진 수평선 바로잡기

바다나 건물 사진의 수평선이 살짝 기울었다면 세부 각도를 0.5도 단위로 돌려 맞춰 보세요. 사진을 돌리면 네 귀퉁이에 빈 삼각형이 생기는데, '잘라서 채우기'를 고르면 빈 곳이 보이지 않는 가장 큰 사각형만 남겨요. 대신 가장자리가 조금 잘려 나가요. 가장자리를 살리고 싶다면 흰색이나 투명으로 채우면 돼요.

좌우 반전은 언제 쓰나요

전면 카메라로 찍은 셀카는 거울처럼 좌우가 뒤집혀 저장되는 경우가 있어서, 옷에 적힌 글자가 거꾸로 보여요. 좌우 반전을 한 번 누르면 실제 모습대로 돌아와요. 상하 반전은 물에 비친 반영처럼 대칭 효과를 만들 때 써요. 회전과 반전은 여러 번 눌러도 순서대로 계산돼서, 미리보기에 보이는 그대로 저장돼요.

스캔한 문서가 비뚤어졌을 때

휴대폰으로 찍은 영수증이나 서류가 살짝 기울어 있으면 읽기도 불편하고 PDF로 묶었을 때 보기 좋지 않아요. 세부 각도를 1~3도쯤 돌려 글자 줄이 수평이 되게 맞춘 뒤 '흰색'으로 빈 곳을 채우면 스캔한 것처럼 반듯해져요. 그다음 이미지 → PDF로 묶으면 제출용 문서가 돼요.

자주 묻는 질문

회전하면 화질이 떨어지나요?

90°·180° 회전과 반전은 픽셀 위치만 바꿔서 화질 변화가 거의 없어요. 세부 각도 회전은 픽셀을 다시 계산하기 때문에 아주 약간 부드러워질 수 있어요.

여러 장을 각각 다르게 돌릴 수 있나요?

한 번에 적용하는 설정은 모든 사진에 같게 들어가요. 방향이 서로 다른 사진은 방향별로 나눠서 두세 번에 걸쳐 처리하면 빨라요.

미리보기와 결과가 달라요.

미리보기는 첫 번째 사진만 보여 줘요. 다른 사진은 가로·세로 비율이 달라서 '잘라서 채우기' 결과가 조금 다를 수 있어요.

사진 파일이 전송되나요?

아니요. 모든 처리는 브라우저 안에서 이뤄지고 사진은 어디로도 보내지지 않아요.
