광고 자리

규칙은 이렇게 만들어요

새 이름 칸에 원하는 글자를 쓰고, 파일마다 달라져야 하는 부분에 꼬리표를 넣어요. {번호}는 시작 번호부터 1씩 늘어나고, {원래이름}은 기존 파일 이름(확장자 제외), {날짜}와 {시간}은 파일을 마지막으로 수정한 날짜·시각(예: 20260921, 143005)으로 바뀌어요. 예를 들어 '제주여행_{날짜}_{번호}'라고 쓰면 '제주여행_20260921_001.jpg'처럼 만들어져요.

번호 자릿수를 001처럼 맞춰 두면 윈도·맥 탐색기에서 이름순 정렬을 했을 때 10번이 2번 앞에 오는 문제가 생기지 않아요. 파일이 100개가 넘는다면 3자리 이상을 고르세요.

찾아 바꾸기로 지저분한 이름 정리

카메라가 붙인 'IMG_'나 'KakaoTalk_Photo_' 같은 앞부분을 지우려면 찾을 글자에 넣고 바꿀 글자는 비워 두세요. 이 규칙은 {원래이름}에 적용되니, 새 이름 규칙을 '{원래이름}'으로 두면 해당 글자만 지운 이름이 돼요. 이름이 겹치면 뒤에 (2), (3)을 붙여 덮어쓰지 않게 해요. 윈도에서 파일 이름에 쓸 수 없는 기호(\ / : * ? " < > |)는 자동으로 밑줄로 바꿔요.

원본 파일은 그대로예요

브라우저는 보안상 컴퓨터에 있는 파일의 이름을 직접 바꿀 수 없어요. 그래서 이 도구는 이름을 바꾼 사본을 ZIP 하나로 묶어 내려받게 해요. ZIP을 풀면 새 이름의 파일이 나오고, 원본은 원래 자리에 그대로 남아 있어요. 파일 내용은 한 바이트도 바뀌지 않아요.

자주 묻는 질문

사진 말고 다른 파일도 되나요?

네. PDF, 한글·워드 문서, 동영상 등 어떤 파일이든 이름을 바꿀 수 있어요.

촬영한 날짜로 이름을 붙일 수 있나요?

{날짜}는 파일의 마지막 수정 날짜를 써요. 휴대폰에서 바로 옮긴 사진은 대개 촬영 날짜와 같지만, 편집하거나 메신저로 받은 사진은 받은 날짜가 될 수 있어요.

파일이 아주 많으면요?

수백 개도 되지만 전체 용량이 수 GB라면 ZIP을 만드는 동안 기기 메모리가 부족할 수 있어요. 나눠서 처리하는 걸 권해요.

파일이 서버로 올라가나요?

아니요. 이름 바꾸기와 ZIP 만들기 모두 브라우저 안에서 이뤄져요.
