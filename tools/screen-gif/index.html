🖥️ 화면 녹화 → GIF

프로그램 사용법, 버그 재현 과정, 짧은 시연을 녹화해서 바로 움짤로 만들어요. 설치할 것 없이 크롬·엣지 브라우저만 있으면 돼요.

이 브라우저는 화면 녹화를 지원하지 않아요. PC의 크롬이나 엣지에서 열어 주세요. 휴대폰 브라우저는 화면 녹화 기능을 제공하지 않아요.

파일은 서버로 올라가지 않고 이 브라우저 안에서만 처리돼요.

광고 자리

녹화하는 순서

'녹화 시작'을 누르면 브라우저가 무엇을 공유할지 물어봐요. 전체 화면, 특정 창(예: 엑셀, 포토샵), 크롬의 특정 탭 중에서 고르면 바로 녹화가 시작돼요. 설명하고 싶은 동작을 한 뒤 '녹화 끝내기'나 브라우저 상단의 '공유 중지'를 누르면 GIF가 만들어져요. 최대 녹화 시간이 지나면 자동으로 멈춰요.

녹화한 화면은 GIF와 함께 영상(WEBM)으로도 저장할 수 있어요. GIF는 메신저·노션·깃허브 이슈에 붙이면 바로 재생돼서 편하고, 영상은 용량이 훨씬 작고 화질이 좋아서 길게 녹화했을 때 유리해요.

보기 좋은 GIF를 위한 팁

전체 화면보다 필요한 창 하나만 공유하면 글자가 크게 담기고 용량도 줄어요. 모니터 해상도가 높으면 가로 480~640px로 줄였을 때 작은 글자가 뭉개질 수 있으니, 녹화 전에 브라우저나 프로그램을 확대(Ctrl + 휠)해 두면 훨씬 잘 읽혀요. 마우스는 천천히 움직이고, 클릭한 뒤 결과가 보일 때까지 1초쯤 기다려 주면 보는 사람이 따라가기 쉬워요.

재생 속도를 1.5배나 2배로 두면 입력을 기다리는 지루한 구간이 빨리 지나가고 용량도 줄어요. 개인정보가 보이는 알림이나 메신저 창은 녹화 전에 꺼 두세요. 녹화된 화면은 브라우저 밖으로 전송되지 않고 이 기기 안에서만 GIF로 만들어져요.

자주 묻는 질문

휴대폰에서도 되나요?

휴대폰 브라우저는 화면 녹화 기능을 제공하지 않아요. 휴대폰 기본 화면 녹화로 영상을 찍은 뒤 영상 → GIF 도구로 바꾸면 돼요.

소리도 녹음되나요?

GIF에는 소리를 담을 수 없어서 소리는 녹음하지 않아요.

맥에서 화면 공유가 안 돼요.

맥은 처음 한 번 시스템 설정 › 개인정보 보호 및 보안 › 화면 기록에서 크롬(또는 엣지)을 허용해야 해요. 허용한 뒤 브라우저를 다시 열어 주세요.

녹화 내용이 어딘가로 전송되나요?

아니요. 화면은 브라우저 안에서만 캡처되고 GIF도 기기 안에서 만들어져요.
