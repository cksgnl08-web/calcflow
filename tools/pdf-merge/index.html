📎 PDF 합치기

계약서, 증빙 서류, 스캔 파일처럼 나뉘어 있는 PDF를 하나로 합쳐요. 순서를 위아래로 바꾼 뒤 한 번에 병합할 수 있어요.

📄PDF 파일을 여기로 끌어오거나 눌러서 선택여러 개 한 번에 · 파일은 전송되지 않아요

파일은 서버로 올라가지 않고 이 브라우저 안에서만 처리돼요.

광고 자리

합치기 전에 순서를 정하세요

PDF는 목록에 보이는 순서대로 이어 붙여져요. 파일 오른쪽의 ↑↓ 버튼으로 순서를 바꾸고, 잘못 넣은 파일은 ✕로 빼면 돼요. 각 파일의 쪽수와 합쳤을 때 전체 쪽수가 함께 보여서, 빠진 파일이 없는지 확인하기 쉬워요. 파일 안의 일부 페이지만 넣고 싶다면 먼저 PDF 나누기로 필요한 페이지만 뽑은 뒤 합치세요.

자주 쓰는 경우

입사 지원이나 대출·전세 서류 제출처럼 '파일 1개로 첨부'를 요구하는 곳이 많아요. 주민등록등본, 재직증명서, 소득금액증명원을 각각 발급받으면 PDF가 여러 개가 되는데, 이 도구로 합쳐서 한 번에 올리면 돼요. 스캐너로 앞면과 뒷면을 따로 스캔한 경우에도 순서를 맞춰 합칠 수 있어요. 사진이나 캡처 이미지를 함께 넣어야 한다면 이미지 → PDF로 먼저 PDF로 바꾼 뒤 합치면 돼요.

파일이 밖으로 나가지 않아요

계약서나 증명서처럼 민감한 서류는 온라인 변환 사이트에 올리기가 꺼려져요. 이 도구는 PDF를 서버로 보내지 않고 브라우저 안에서 페이지를 복사해 새 파일을 만들어요. 원본 페이지를 그대로 복사하기 때문에 글자·이미지 화질이 떨어지지 않고, 글자 선택이나 검색도 원본처럼 동작해요.

합친 파일이 너무 크다면

스캔본이 섞여 있으면 합친 PDF가 수십 MB가 되기도 해요. 합치기는 페이지를 그대로 복사하기 때문에 용량이 줄지 않아요. 제출처 제한을 넘는다면 스캔할 때 해상도를 200~300dpi로 낮추거나, 사진으로 찍은 서류는 이미지 용량 줄이기로 먼저 줄인 뒤 이미지 → PDF로 만들어 합치는 방법이 가장 효과적이에요. 반대로 합친 파일을 다시 쪼개야 한다면 PDF 나누기의 'N쪽씩 나누기'로 용량에 맞게 나눌 수 있어요.

자주 묻는 질문

암호가 걸린 PDF도 합칠 수 있나요?

열람 암호가 걸린 PDF는 열 수 없어요. PDF 뷰어에서 암호를 풀고 다시 저장한 파일을 넣어 주세요.

몇 개까지 합칠 수 있나요?

개수 제한은 없어요. 다만 전체 용량이 수백 MB를 넘으면 기기에 따라 느려지거나 멈출 수 있어요.

책갈피(목차)나 입력 양식은 유지되나요?

페이지 내용과 링크 대부분은 유지되지만, 원본 파일의 책갈피 목록과 일부 입력 양식은 합친 파일에 옮겨지지 않을 수 있어요.

휴대폰에서도 되나요?

네. 파일 앱이나 다운로드 폴더의 PDF를 선택하면 돼요. 합친 파일은 다운로드 폴더에 저장돼요.
